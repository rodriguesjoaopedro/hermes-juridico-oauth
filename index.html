Hermes Jurídico Backup

Integração pessoal utilizada para armazenar backups criptografados do projeto Hermes Jurídico no Google Drive.

Funcionamento

O sistema utiliza Rclone para a comunicação com o Google Drive e Restic para criar backups criptografados.

O acesso ao Google Drive depende de autorização OAuth 2.0 concedida pelo proprietário da conta.

Esta integração é destinada exclusivamente ao uso pessoal do responsável pelo projeto.
